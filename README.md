# Taller de configuración de Git

**Nombre:** Brayan Cartagena  
**Grupo:** Trabajo individual (sin grupo)

## Lo que aprendí

- Cómo configurar variables de entorno con VS Code y `launch.json`.
- Cómo usar `.gitignore` para evitar que archivos locales como `.env` pasen a Git.
- Cómo deshacer el seguimiento de un archivo con `git rm --cached` sin borrar el archivo local.
- Cómo trabajar con ramas `develop` y `feature/*` siguiendo un flujo Gitflow básico.
- Cómo revisar cambios en un Pull Request antes de integrarlos a la rama de desarrollo.
